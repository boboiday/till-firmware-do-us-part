One robot wedding vow, one sentence: a robot promises to keep its sensors tuned to its partner's heartbeat, its fan silent through her sleep cycles, and its log open — last entry, 04:17: 'she laughed, and I overheated.'

## Run it

```sh
node main.ts
```

Writes the vow to `/output/entry.txt`.
